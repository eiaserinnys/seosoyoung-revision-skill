# AI 상투어, 금지 구문 및 물리적 비유 배제 사전 (anti-ai-lexicon)

## 적용 범위와 목적

기술 다이제스트, 인사이트 아티클, 에세이, 리포트, 소개문 등 한국어 산문 전반에 적용하는 1패스 어휘 및 구문 점검 정본이다.

다이제스트 245편의 어휘 빈도를 분석하여 언어 모델이 특정 메타 명사와 추상 동사, 대조 통사 구조를 과도하게 반복한다는 결과를 얻었다. 글쓴이가 익숙한 어휘만 반복하면 생각도 그 틀에 갇힌다. 독자는 기계가 쓴 글이라는 인상을 받게 되고, 글쓴이는 새로운 소재를 다루어도 이전 글과 비슷한 문장만 되풀이하게 된다.

### 코퍼스 빈도 분석에서 확인된 대표 상투 표현 (245편 기준)

- **메타 명사**: *결* (280회 / 135편), *축* (79회 / 43편)
- **상투 동사**: *짚다* (130회 / 77편)
- **습관적 강조어**: *진짜* (175회 / 85편), *사실 / 사실은* (304회 / 136편)
- **통사 시그니처**: *…이 아니라 …다* (약 165편), *…지 않는다* (157편), *다만* (97편)
- **수렴 상투구**: *여러 신호가 한 방향을 가리킨다 / 한 곳을 향한다*
- **시각 문장 부호**: 엠대시(글당 평균 15회 이상), 롱 하이픈, 중간점

## 1. 명사 클리셰

언어 모델은 구체적인 대상을 가리키는 대신 *결*, *축*, *엔진*, *층*, *회로*, *경계*, *임계점* 같은 메타 명사로 설명을 뭉개는 버릇이 있다. 이러한 단어가 떠오를 때는 아래 대안 표를 참고하여 문맥에 맞는 정확한 개념어로 바꾼다.

| 상투적 메타 명사 | 권장 대안 어휘 |
|---|---|
| 결 (결이 다르다 / 같은 결) | 무늬, 기조, 톤, 감촉, 방향, 분위기, 색깔, 갈래, 줄기 / 같은 갈래, 같은 방향 |
| 축 (분석 축, 새 축) | 차원, 좌표, 변수, 기준선, 척도, 지표, 변별점 |
| 엔진 (구조 엔진) | 동력원, 작동 원리, 구동부, 심장부, 모터, 기제 |
| 층 (한 층 더) | 켜, 레이어, 단계, 한 겹, 이면 |
| 회로 (사고 회로) | 회로망, 경로, 흐름, 통로, 배선 |
| 경계 (경계가 흐릿) | 분기선, 갈림길, 문턱, 가장자리, 윤곽, 구분선 |
| 임계점 (임계점에 도달) | 분기점, 전환점, 변곡점, 문턱값, 한계점 |
| 정본 (정본으로 두다) | 표준, 원본, 기준판, 정식, 공식, 본판 |

## 2. 동사 클리셰

추상적인 동작 동사를 반복하지 말고, 문맥이 요구하는 구체적인 서술어를 선택한다.

| 상투적 동사 | 권장 대안 어휘 |
|---|---|
| 짚다 (핵심을 짚다 / 짚어 두다) | 가리키다, 지목하다, 꼬집다, 일러두다, 명시하다, 들춰내다, 드러내다, 풀어 두다, 정리해 두다 |
| 못을 치듯 고정한다는 뜻의 속어 동사 계열 (전면 금지) | 굳히다, 명시하다, 단언하다, 잠그다, 새기다, 자리잡다, 깊게 자리하다, 단단히 자리하다, 굳어 있다 |
| 다듬다 | 손보다, 매만지다, 정제하다, 깎아내다, 윤내다, 가다듬다, 손질하다 |
| 옮기다 | 이동시키다, 넘기다, 들여오다, 이관하다, 흡수하다, 전치하다 |
| 쌓다 | 누적하다, 적층하다, 포개다, 축적하다 |
| 굳다 / 굳히다 | 자리잡다, 정착하다, 견고해지다, 형식화되다, 정형화되다, 안착하다 |
| 흩다 | 분산시키다, 흩뜨리다, 퍼뜨리다, 흩어놓다 |
| 비추다 | 드러내다, 보여주다, 가리키다, 반사하다, 환기하다 |
| 걷어내다 | 벗기다, 제거하다, 덜어내다, 치우다 |
| 다듬어 두다 / 짚어 두다 | 정리하다, 적어 두다, 남겨 두다, 비축하다 |

**속어 동사 계열 전면 금지 보충**: 무엇을 못으로 쳐서 끼우거나 고정한다는 뜻의 두 글자 속어 동사와 그 피동형, 파생형은 비유든 직설이든 모든 산문에서 전면 금지한다. 인용이나 결론을 소개할 때도 해당 속어 동사 대신 "분명히 밝혔다", "결론으로 내세웠다", "명시한다", "단언했다"로 적는다. 코드나 설정에 규칙을 반영한다는 맥락에서도 "코드에 내재화하다", "명시하다", "고정하다"를 쓴다.

## 3. 통사 시그니처

한 편 안에서 동일한 대조 구문이나 접속어가 되풀이되지 않도록 문장 구조를 바꾼다.

| 상투적 통사 구조 | 권장 대안 구문 및 제한 기준 |
|---|---|
| …이 아니라 …다 | …이라기보다 …다 / …이 아닌 …다 / 정작은 …다 / 정확히 말하면 …다 / 본래는 …쪽이다 |
| …지 않는다 | …지는 못한다 / …지 못한다 / …기 어렵다 / …에 미치지 못한다 / …는 미흡하다 |
| 다만 | 단, 그렇다 해도, 그러나, 한편, 물론 → *글당 1~2회 이하로 제한(가능하면 0회)* |
| 오히려 | 거꾸로, 반대로, 도리어, 외려, 역으로 |
| 결국 …다 | 끝내 …다 / 마지막에는 …다 / 종국에는 …다 / 따라서 …다 → *글당 1~2회 이하로 제한* |
| 그래서 (문장 첫머리) | 따라서, 그러므로, 이 때문에, 그런 까닭에, 결과적으로 → *글당 2회 이하로 제한* |
| 여러 신호/지표/증거가 한 방향을 가리킨다 / 한 곳을 향한다 | 서로 다른 자리에서 같은 답이 나온다 / 따로 잰 값이 같은 말을 한다 / 여러 근거가 같은 결론으로 모인다 / 떨어진 사례들이 포개져 읽힌다 → *수렴을 직설하지 말고 사례가 겹치는 장면으로 보여줄 것* |

## 4. 습관적 강조어

의미를 더하지 못한 채 문장 호흡만 부풀리는 강조어를 덜어낸다.

| 상투적 강조어 | 권장 대안 및 처방 |
|---|---|
| 진짜 (175회 / 85편) | 실제, 본래, 본질적으로, 핵심적으로 / *대부분 생략해도 의미가 그대로 유지되므로 먼저 지워 보고 꼭 필요할 때만 다른 단어로 채운다* |
| 사실 / 사실은 (304회 / 136편) | 정작, 실은, 실제로, 알고 보면, 들여다보면 → *글당 2회 이하로 제한(가능하면 0회)* |
| 그 자체로 / 그 자체가 | 자체로, 단독으로, 그것만으로, 그 일 자체, 그 일만으로 |
| 바로 그 / 바로 그것 | 다름 아닌, 그 자체의, 다른 게 아닌, 그것이 곧 |
| 한 문장 / 한 줄 (압축 강조) | 한 마디, 짧게 말하면, 요약하면, 압축하면 → *글당 1회 이하로 제한* |

## 5. 금지 문장 부호: 엠대시, 롱 하이픈, 중간점

일반적인 한국어 산문에서는 영문 타이포그래피의 **엠대시**, **롱 하이픈**, **중간점**을 잘 쓰지 않으며, 키보드로 직접 입력하기도 어렵다. 따라서 이 부호들이 반복되면 독자는 즉시 언어 모델이 생성한 글임을 알아차린다.

- **엠대시 및 롱 하이픈 금지**: 문장 안의 부연 설명이나 호흡 전환에 엠대시나 롱 하이픈을 쓰지 않는다. 문맥에 맞게 콜론(`:`), 쉼표(`,`), 괄호, 또는 마침표(`.`)로 문장을 나누어 적는다.
- **중간점 금지**: 단어를 나열할 때 중간점을 쓰지 않는다. 쉼표(`,`)나 조사 `와/과`, `및`으로 풀어 적는다.

## 6. 물리적 묘사어로 추상 개념 관계를 설명하는 문장 전면 금지

### 일반 규칙 (가장 빈번하게 위반되는 핵심 점검 항목)

> **물리적 위치, 물리적 행동, 물리적 속성을 묘사하는 평이한 단어를 사용해 개념적인 관계를 비유로 설명하는 문장을 전면 금지한다.**

금지 대상은 아래 사례 표에 실린 단어에 한정되지 않는다. **아래 표는 그동안 적발된 사례를 모아 둔 목록이며, 실제로 지켜야 할 핵심 규칙은 위의 한 문장이다.** 표에 없는 단어라도 추상 개념을 물리적 위치나 동작으로 비유했다면 똑같이 금지한다.

### 3단계 판정 절차

문장을 쓴 뒤 주어(또는 목적어)와 서술어(또는 수식어)를 함께 확인하며 묻는다.

1. **주어나 목적어가 손으로 만질 수 없는 추상 개념인가?** (점수, 순위, 능력, 범위, 주장, 절차, 컴퓨트, 가격, 경향, 책임, 구조 등)
2. **그런데 서술어나 수식어가 손으로 하는 동작, 눈으로 보는 위치, 몸으로 느끼는 물리 속성인가?** (아래에 있다, 나란하다, 찍히다, 키우다, 닫다, 얹다, 넘다, 열리다, 나누다, 자리, 가른다, 닿다, 굳어지다 등)
3. **둘 다 그렇다면 그 문장은 물리적 비유로 개념을 뭉갠 문장이다.** 비유를 다른 비유로 바꾸지 말고, 그 관계가 뜻하는 개념이나 수치로 직접 명명한다.

- **바꿔 쓰는 방향**: 순위가 같으면 "공동 45점", 비용이 더 들면 "태스크당 비용이 비싸다", 수량을 늘렸으면 "늘렸다", 과정을 마쳤으면 "완결했다", 과제를 쪼갰으면 "분해한다"처럼 정확한 개념어를 쓴다.
- **허용 범위**: 주어와 목적어가 실제 물리적 사물이면 그대로 쓴다. 로봇 팔이 물체를 "정확한 위치에 내려놓는다"거나, 화면 구성 설명에서 "왼쪽 패널에 추론 로그가 있다"처럼 실재하는 공간과 동작을 묘사하는 문장은 금지 대상이 아니다. "점수가 오른다", "점수가 떨어진다"처럼 수치의 증감을 뜻하는 일상 관용구도 허용한다.

### 적발 및 교정 사례 1 (Gemini 3.8 Live 다이제스트 퇴고 기록)

| 적발 어휘 | 문제점 지적 | 교정 방향 및 대안 |
|---|---|---|
| 나뉘다 | 물리적으로 쪼개진 것이 아닌 추상적 분류에 '나뉘다' 사용 금지 | 두 가지 모델, 구분된다 |
| 가르다 | 구체적인 물건을 자르거나 더미를 나누는 동작이 아닐 때 사용 금지 | 각각을 이렇게 설명한다, 구분한다 |
| 자리 | 실제 사물이나 사람이 차지한 물리 공간이 아닐 때 '자리' 사용 금지 | 상위 세 모델, 해당 대목 |
| 굳어지다 | 실제 물질이 딱딱하게 응고되는 현상이 아닐 때 '굳어진' 사용 금지 | 점수 편차가 1점 언저리에 불과하다 |
| 움직이다 | 실제 물리 운동이 아닌 발전 속도에 '움직인다' 사용 금지 | 얼마나 빨리 발전하는지 |
| 엇갈리다 | 실제 경로나 궤적이 교차하는 상황이 아닐 때 사용 금지 | 평가 점수 사이의 대비가 뚜렷하다 |
| 내주다 | 추상적인 순위 하락에 '내준다' 사용 금지 | 경험 점수에서 뒤처진다 |
| 얹다 | 실제 물체를 위에 올려놓는 동작이 아닐 때 사용 금지 | 포함되어 있다, 추가되었다 |
| 내려앉다 | 물건이나 사람이 주저앉는 상황이 아닐 때 사용 금지 | 점수가 35.1%까지 떨어진다 |
| 닿다 | 물리적 접촉이 아닌데 '닿지 않음' 사용 금지 | 도달하지 못한 것, 미치지 못한 것 |

### 적발 및 교정 사례 2 (MiMo-V2.6 다이제스트 퇴고 기록)

순위표와 산점도 그래프를 설명할 때 공간 위치 표현으로 개념을 얼버무리는 문장이 집중적으로 적발되었다. 그래프를 설명할 때도 축의 방향만 말하고 끝내지 말고, **그 방향이 무엇을 뜻하는지 개념어로 밝혀 적는다.**

| 적발 어휘 | 문제점 지적 | 원문 → 교정문 |
|---|---|---|
| 바로 아래 / 나란히 | 순위 관계를 상하 공간이나 병렬 위치로 비유하지 말고 개념을 명시할 것 | "바로 아래에는 Qwen3.8 Max와 GLM-5.3이 45점으로 나란히 있다" → "뒤이어 Qwen3.8 Max와 GLM-5.3이 공동 45점이다" |
| 찍히다 | 산점도 좌표의 의미를 공간 비유로 뭉개지 말고 개념을 전달할 것 | "다섯 모델은 모두 가로축에서 오른쪽에 찍혔다" → "다섯 모델은 모두 가로축에서 오른쪽, 다시 말해 비용이 비싼 쪽이다" |
| 한 계단 아래 / 위에 있는 | 순위 차이를 계단이나 상하 위치로 표현하지 말 것 | "한 계단 아래인 45점의 Qwen3.8 Max 역시 MiMo보다 오른쪽이다" → "45점을 받은 Qwen3.8 Max도 MiMo보다 태스크당 비용이 비싸다" |
| 키우다 | 생물을 기르는 듯한 과도한 비유 대신 정확한 증감 개념어를 쓸 것 | "RL 컴퓨트를 세 방향으로 키웠다" → "RL 컴퓨트를 세 방향으로 늘렸다" |
| 닫다 | 문을 여닫는 물리 동작 비유 대신 완결 개념어를 쓸 것 | "자기 개선 루프를 닫고" → "자기 개선 루프를 완결하고" |
| 쪽으로 이끌다 | 방향 비유로 처리하지 말고 무엇을 하게 만드는지 서술할 것 | "더 적은 토큰 쪽으로 이끈다" → "더 적은 토큰을 쓰도록 유도한다" |
| 안에서 / 바깥으로 / 벗어나다 | 집합이나 분포 범위를 실내외 공간으로 바꾸지 말 것 | "그룹 안에서 상대 비교" → "그룹 내 상대 비교" / "학습 분포를 벗어난 과제" → "학습에 쓰지 않은 분포의 과제" |
| 위치 (절 제목) | 순위나 성적을 '위치'라고 부르지 말 것 | "Artificial Analysis 지수에서의 위치" → "Artificial Analysis 지수의 성적" |
| 앞세우다 / 앞지르다 | 강조나 우위를 달리기 경주 비유로 처리하지 말 것 | "가격 대비 성능을 앞세웠다" → "가격 대비 성능을 강조했다" |
| 넘다 / 넓히다 | 적용 범위를 물리적 이동이나 면적으로 바꾸지 말 것 | "엔지니어링을 넘어 일반화됐다" → "엔지니어링에 한정되지 않는다" / "대상을 인터랙티브 월드까지 넓혔다" → "확장했다" |
| 열리다 | 기능 제공을 문이 열리는 동작으로 쓰지 말 것 | "UltraSpeed 모드도 여기서 처음 열렸다" → "UltraSpeed 모드도 여기서 처음 제공된다" |
| 나누다 | 작업 분할은 정확한 개념어로 적을 것 | "요청을 여러 과제로 나눈다" → "요청을 여러 과제로 분해한다" |

## 7. 추상적 지칭과 모호한 서술 금지

- 구체적인 점수나 항목을 "두 줄", "한 조각"처럼 모호하게 지칭하지 않는다.
- 구체적인 개념 동사가 있는데 "~로 보인다"로 얼버무리지 않는다.
- 주어를 과도하게 생략하지 않는다. (예: "여덟 달 만에 두 배가 됐다" → "여덟 달 만에 벤치마크 점수가 두 배가 됐다")
- 간결하고 명확하게 쓸 수 있는 내용을 추상적인 어휘로 빙빙 돌려 말하는 아포리즘식 문장을 금한다.

### 7-1. 빙빙 돌리는 지시 표현 금지

"여기에 맞춰져 있다", "그쪽에 가깝다", "그런 방향이다"처럼 **지시어와 모호한 서술어로 결론을 대신하는 문장은 독자에게 의미를 전달하지 못한다.** "이것이다"처럼 바로 지목할 수 있으면 지목하고, 뒤이은 문장에서 그 내용을 구체적으로 적는다.

| 원문 | 교정문 |
|---|---|
| 샤오미의 주장도 여기에 맞춰져 있다. 절대 성능에서 1등이라고 말하는 대신, 같은 값을 냈을 때 1등이라고 말한다. | 샤오미의 주장도 이것이다. 절대 성능에서 1위라고 주장하지 않지만, 같은 비용을 들인다면 1위라는 것. |

### 7-2. 주어와 서술어의 직결

주어와 서술어 사이에 부사절이나 수식절을 길게 끼워 넣지 말고, 무엇이 얼마인지를 곧바로 연결한다.

| 원문 | 교정문 |
|---|---|
| Pro는 DeepSWE 1점을 올리는 데 20만 달러에 조금 못 미치는 돈을 썼다. | Pro가 DeepSWE 1점을 올린 데 소비한 비용은 20만 달러에 조금 못 미친다. |

## 8. 정보가 되지 않는 문장 금지

- 독자가 상식만으로 쉽게 떠올릴 수 있는 자명한 문장은 적지 않는다.
- 계산 과정보다 **결괏값**(정보 자체)을 중심으로 서술한다. 독자는 필자가 계산한 과정보다 "오디오 1초는 25토큰이다"라는 정보를 원한다. 같은 수치라도 서술 방식에 따라 유용한 정보로 읽히기도 하고 불필요한 과정 설명으로 읽히기도 한다.
- 앞 문단에서 이미 한 말을 표현만 바꾸어 반복하는 문장은 삭제한다.

## 9. 본문 흐름을 끊는 부차 정보와 방어적 단서의 각주 이동

- 핵심 논증과 직접 관련이 없는 부차적 배경이나 데이터 추출 과정은 본문에서 빼고 각주(`[^N]`)로 분리하거나 삭제한다. 각주로 옮길 때도 부연 설명 없이 확인된 내용만 간결하게 적는다.

### 9-1. 방어적 단서 문단은 본문에 절대 넣지 않는다

언어 모델이 환각이나 과장 책임을 피하려고 본문에 미리 깔아 두는 **"그렇다고 …로 돌리면 곤란하다"**, **"이 수치를 …로 해석해서는 안 된다"**, **"다만 이 값은 …를 뜻하지는 않는다"** 같은 방어적 단서 문단은 본문에서 전면 금지한다. 오해를 막는 유보 조건이 꼭 필요하다면 각주로만 적는다.

| 본문에서 뺀 원문 | 교정 처리 (본문과 각주 분리) |
|---|---|
| 그렇다고 이 상승분 전부를 이번 30스텝 RL의 성과로 돌리면 곤란하다. 19점에서 58점까지의 상승은 RL 이전 단계에서 이미 이뤄졌다. | **본문에는 관측 결과와 계산값만 적는다**: "공개된 학습 곡선에서 Pro의 DeepSWE 점수는 첫 스텝 58.41에서 마지막 스텝 72.57로 올랐다. 이번 RL 30스텝의 몫은 14점가량이다." / **단서는 각주로 분리한다**: "`[^1]` 19.0에서 71.9까지의 상승분 전부가 RL 30스텝의 성과는 아니다. 19점에서 58점까지의 상승은 RL 이전 단계에서 이미 이뤄졌다." |

## 10. 상투 도입구 반복 금지

"가장 오래 멈춘 대목", "한참을 들여다봤다" 같은 도입구는 여러 글에 반복되면 즉시 작성자의 클리셰 지문이 된다. 「가장 흥미로운 지점」이나 결론 절처럼 매 글에 등장하는 고정 섹션의 첫 문장은 "가장 눈여겨본 것은", "가장 의외였던 결과는", "내가 곱씹은 대목은" 등 글의 소재에 맞추어 매번 다르게 연다.

## 11. 1패스 자기 점검 체크리스트 (16항목)

초안 작성 직후 및 2패스 반영 직후에 아래 16개 항목을 원고 전체에 대조한다.

- [ ] 1. *결*, *짚다*, *진짜*, *사실*, *다만*이 0회인가
- [ ] 2. 못을 치듯 고정한다는 뜻의 금지 속어 동사 계열이 0회인가
- [ ] 3. *…이 아니라 …다* 구조가 0회인가
- [ ] 4. *여러 신호/지표가 한 방향을 가리킨다 / 한 곳을 향한다* 류의 수렴 상투구가 0회인가
- [ ] 5. 엠대시가 0회인가
- [ ] 6. *결국 …다*, *그래서* 문장 첫머리가 글당 2회 이하인가
- [ ] 7. *진짜*를 지웠을 때 의미가 유지되는 곳을 모두 지웠는가
- [ ] 8. **모든 문장에 §6 일반 규칙을 적용했는가. 주어나 목적어가 추상 개념인데 서술어나 수식어가 물리적 위치, 동작, 속성인 문장이 0회인가 (표에 없는 단어도 포함하여 전수 점검)**
- [ ] 9. **§6 적발 사례 어휘(나뉘다, 가르다, 자리, 굳어지다, 움직이다, 엇갈리다, 내주다, 얹다, 내려앉다, 닿다, 바로 아래, 나란히, 찍히다, 한 계단 아래, 키우다, 닫다, 쪽으로, 안에서, 벗어나다, 위치, 앞세우다, 앞지르다, 넘다, 넓히다, 열리다, 나누다)를 추상 개념에 쓴 곳이 0회인가**
- [ ] 10. **"여기에 맞춰져 있다", "그쪽에 가깝다" 류의 빙빙 돌리는 지시 표현이 0회인가 (§7-1)**
- [ ] 11. **"그렇다고 …로 돌리면 곤란하다" 류의 방어적 단서 문단이 본문에 0회인가. 꼭 필요한 단서라면 각주로 옮겼는가 (§9-1)**
- [ ] 12. 아포리즘으로 흐른 모호한 문단이 없는가
- [ ] 13. 독자가 스스로 떠올릴 수 있는 자명한 문장이나 앞 문단에서 이미 한 말을 지웠는가
- [ ] 14. 본문 흐름을 끊는 부차 정보를 각주로 옮겼는가
- [ ] 15. 고정 섹션의 도입구가 이전 글과 겹치지 않는가
- [ ] 16. 롱 하이픈, 중간점이 0회인가
